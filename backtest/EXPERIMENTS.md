# บันทึกผลการทดลองและหลักฐาน — Signal Engine

รวบรวมทุกการทดลอง ผลตัวเลข และข้อสรุปเกี่ยวกับ signal engine ของ stockLinebot-api
(และผลต่อ StockBot / AI Insight / Dashboard) เรียงตามลำดับเวลา
ไฟล์ผลดิบอยู่ใน `backtest/results/` (gitignored — สร้างใหม่ได้ด้วยคำสั่งในหัวข้อ "ทำซ้ำ")

**สรุปสั้นที่สุด:** engine v2 ที่ใช้อยู่ **ไม่ได้ทายทิศทางราคาแม่นกว่าการโยนเหรียญ**
จุดแข็งที่พิสูจน์ได้คือ **คุมความเสี่ยง (drawdown ตื้นกว่ามาก) + สัญญาณมีความหมายตรงชื่อ +
เปลี่ยนสัญญาณน้อยลง ~3 เท่า** และในหุ้นชุดกว้าง **ไม่มีสูตรที่ทดสอบสูตรไหนชนะ SPY / การถือเฉยๆ
ในแง่ Sharpe** (รวม momentum ranking)

## 0. วิธีการ (ใช้กับทุกการทดลอง)

- **Harness** (`backtest/`): replay engine ย้อนหลังด้วยข้อมูลรายวัน yfinance (`auto_adjust=True`,
  แหล่งเดียวกับ production) แบบ point-in-time — วันที่ t ใช้ข้อมูลถึง t เท่านั้น
- **engine เดิม (v1)** replay ทีละวันบนหน้าต่าง 90 วันปฏิทินแบบเดียวกับที่ API ดึงจริง
  ใช้ `fast_indicators()` ที่ตรวจแล้วว่าให้ค่า **เท่ากับ production ทุกตัว (diff 0.0)**
- **engine v2** — backtest เรียก `recommend_v2_frame()` ตัวเดียวกับ production โดยตรง
  (ตรวจแล้ว 74,824 แถว ต่างกัน 0)
- **การเข้าซื้อ:** สัญญาณของวัน t รู้หลังปิดตลาด → เข้า **open ของวัน t+1**
  (momentum/portfolio test ใช้ close t+1 และหักค่าธรรมเนียม 0.1%/turnover)
- **ตัววัด:** forward return 1/5/10/20 วัน, **excess vs SPY**, hit rate (% ชนะ SPY),
  calibration ของ confidence, คุณภาพ vote ของแต่ละ indicator, พอร์ต long/flat equal-weight
  (BUY เข้า / SELL ออก / HOLD ถือต่อ)
- **ช่วงข้อมูล:** 2021-01-01 → 2026-11-06; in-sample 2021–2024, out-of-sample 2025-01 →
- **universe:** watchlist ปัจจุบัน 15 ตัว (ถูกเลือกแบบรู้ผลแล้ว — มี bias หุ้นที่ขึ้น) และ
  **หุ้นชุดกว้าง 40 ตัว** (มีทั้งหุ้นดีและแย่: INTC, PYPL, NKE, BA, PFE, DIS, VZ, T, KO, XOM, …)
  ใช้ชุดกว้างเป็นเกณฑ์ตัดสินหลัก

## 3. วิเคราะห์ engine v1 (7-indicator weighted vote)

ปัญหาเชิงออกแบบที่พบจากโค้ด `generate_recommendation()`:
1. indicator ตามเทรนด์ (EMA, MACD, SMA, OBV = น้ำหนัก 4.5) กับสวนเทรนด์ (RSI, BB, Stochastic = 5.0)
   **หักล้างกันเอง** → confidence แทบไม่ถึงระดับ "Strong" (≥80)
2. ใช้ ADX แต่ไม่ใช้ +DI/−DI → ไม่รู้ทิศของเทรนด์
3. `period: 90d` (~62 แท่ง) น้อยเกินสำหรับ EMA50 / ADX warm-up; ไม่มี SMA200
4. MACD (น้ำหนักสูงสุด) ใช้สถานะเหนือ/ใต้เส้น → สัญญาณสลับบ่อย, ไม่มี hysteresis
5. RSI / ADX ไม่ใช่สูตร Wilder มาตรฐาน (เช่น NVDA วันเดียวกัน: ADX v1 = 50.9 vs Wilder = 28.9)

**Backtest v1 (watchlist 15 ตัว, 2021–2026, replay 90 วัน)**

| สัญญาณ | n | excess 5 วัน | hit 5 วัน | excess 20 วัน |
|---|---|---|---|---|
| BUY | 6,001 | +0.19% | 49.6% | +1.24% |
| SELL | 4,788 | **+0.50%** | 50.8% | **+1.80%** |
| HOLD | 11,246 | +0.11% | 49.7% | +0.70% |

- confidence calibration (5 วัน): BUY ที่ conf 40–50 / 50–60 / 60+ ให้ excess +0.19 / +0.18 / +0.21 → **ไม่มีความสัมพันธ์**
- vote ของแต่ละ indicator (excess 5 วันเมื่อ vote BUY ลบเมื่อ vote SELL — บวก = ชี้ถูกทาง):
  Stochastic +0.36, BB +0.30, RSI +0.28 | +DI/−DI −0.08, EMA −0.13, MACD −0.16, OBV −0.27, SMA −0.39
  → กลุ่มสวนเทรนด์ชี้ถูก, กลุ่มตามเทรนด์ชี้ผิด (ในหุ้นชุดนี้ช่วงนี้)
- พอร์ต long/flat: CAGR 17.0%, max DD −24.9%, Sharpe 1.05 (EW buy&hold 26.5% / −46.6% / 0.94; SPY 13.8% / −24.5% / 0.86)
- `current_1y` (กฎเดิม หน้าต่าง 1 ปี): ดีขึ้นเล็กน้อย — CAGR 18.0%, DD −23.4%, Sharpe 1.10

## 8.5 ตัวกรองภาวะตลาด (B) และลด whipsaw (C) — ไม่มีตัวไหนดีกว่า v2 ชัดเจน

## 9. ข้อสรุปรวม

1. **ความแม่นในการทายทิศทาง:** ทุกสูตรที่ทดสอบ (v1, v2, pullback, momentum, B/C variants) ≈ 50% ในหุ้นชุดกว้าง
   — indicator ทางเทคนิครายวันของหุ้นใหญ่แทบไม่มีพลังทำนาย
2. **สิ่งที่ v2 ให้ได้จริง:** drawdown ตื้นกว่าการถือเฉยๆ มาก, SELL ไม่กลับด้าน, churn น้อยลง ~3 เท่า
   แลกกับผลตอบแทนต่ำกว่า (ถือหุ้น ~50% ของเวลา)
3. **ไม่มีสูตรไหนชนะ SPY ในแง่ Sharpe** บนหุ้นชุดกว้าง
4. **confidence ไม่ calibrate** ทั้ง v1 และ v2 — ไม่ควรสื่อเป็นความน่าจะเป็น
5. ระบบเหมาะเป็น **ตัวช่วยคุมความเสี่ยง / เฝ้าดูเทรนด์** มากกว่าตัวทำนายหุ้นที่จะชนะตลาด
   ข้อความถึงผู้ติดตามควรสื่อแบบนี้

## 10. ข้อจำกัดของหลักฐาน

- universe ทั้งสองชุดเป็นหุ้นที่ยังอยู่วันนี้ (survivorship bias); watchlist มี selection bias
- ช่วง 2021–2026 ส่วนใหญ่เป็นตลาดขาขึ้น
- forward window ซ้อนกันในการวัดรายวัน → n ที่มีผลจริงน้อยกว่าที่เห็น
- ข้อ 3–5 ไม่หักค่าธรรมเนียม (ข้อ 8 หัก)
- Yahoo ปรับราคาย้อนหลังตาม split/ปันผล → replay อาจต่างจากที่ API เห็นในวันนั้นเล็กน้อย
- v2 ถูกเลือกหลังเห็นผลช่วงเดียวกับที่ทดสอบ → ผลย้อนหลังของ v2 อาจดีเกินจริงเล็กน้อย;
  หลักฐานที่ไม่มี bias นี้คือ forward test (ข้อ 7) เท่านั้น
